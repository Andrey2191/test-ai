# Тестовое Neowise. AI-помощник для входящих заявок

Ориентир — 45–60 минут. Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Требования

- Node.js 20 или новее
- Зависимостей и ключей нет: используются встроенные модули Node.js

## Запуск приложения

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

Проверка API без браузера (кавычки JSON сохраняются):

```sh
node --input-type=module -e "const r=await fetch('http://127.0.0.1:3000/api/triage',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({text:'hello'})}); console.log(r.status, await r.text())"
```

Ожидается HTTP 200 и `"status":"ready"`. В PowerShell `curl.exe --data-raw '{"text":"hello"}'` нельзя считать корректным запросом: оболочка снимает кавычки, на сервер уходит `{text:hello}`, и API правильно отвечает HTTP 400 `invalid_input`.

## Запуск тестов

```sh
node --test
```

Тесты поднимают сервер на свободном порту и проверяют `POST /api/triage`: валидацию ввода, успешный разбор и переход в `manual_review` при сбое модели.

## Обработка ошибок

- Некорректный JSON, отсутствующее поле `text`, нестроковое значение или пустая (в том числе из пробелов) строка — HTTP 400 и `{"status":"invalid_input"}`.
- Ответ модели проверяется на сервере: допустимы только темы `delivery`, `pricing`, `other` и непустой строковый `draft`.
- Ожидание модели ограничено 300 мс. Таймаут, ошибка провайдера, некорректный JSON, неизвестная тема или пустой черновик — HTTP 200 и `{"status":"manual_review","topic":null,"draft":null}`. Поздний ответ модели не меняет уже отправленный результат.
- На странице для `ready` показываются тема и черновик. Для `manual_review` предыдущий результат очищается, исходный текст заявки сохраняется, менеджер видит просьбу разобрать заявку вручную.

Для локальной проверки имитатор принимает любой обычный текст. Метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` включают отдельные сценарии сбоя.
